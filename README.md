# 稀饭亮度增强plus

> ⚠️ **仅适用于一加 12（PJD110）**，ColorOS 16 实测通过（16.0.10.501）。
> 其他机型、其他系统版本**请勿刷入**——模块直接替换面板亮度曲线与显示配置，机型不匹配可能出现亮度异常。

一加 12 在 ColorOS 16 上的亮度增强 KernelSU 模块，整合了两个社区亮度模块的思路与改动，做成一个干净的版本。

## 功能

- **提升自动亮度上限**：强光下自动亮度能顶到滑条最满，不再卡在原厂天花板（实测由 88% → 100%）
- **解锁面板高光端**：抬高面板曲线在强光区间的目标亮度，并在曲线末端补充更高档位
- **放开强光下的亮度限制**：降低面板 HBM（阳光屏）曲线的进入门限，放宽框架侧 HBM 门槛与时长限制
- **保留原模块的其它调整**：面板配置、第三方应用亮度表、多媒体 LTM 配置、关闭高温降亮度保护
- **纯文件挂载**：只 bind mount 覆盖原文件，不改动分区；卸载后自动还原

## 适用环境

| 项目 | 说明 |
|---|---|
| 机型 | 一加 12（PJD110） |
| 系统 | ColorOS 16（实测 16.0.10.501） |
| 依赖 | KernelSU（管理器里安装模块即可） |
| 权限 | 需要 root（KernelSU） |

## 安装

1. KernelSU 管理器 → 模块 → 从本地安装 → 选择 `稀饭亮度增强plus-v2.0.zip`
2. 重启手机生效

## 卸载

KernelSU 管理器里关闭或删除本模块 → 重启，分区原文件自动恢复。

## 验证是否生效

```sh
# 挂载日志：应看到 9 个文件 OK
su -c "cat /data/local/tmp/brightnessplus.log"

# 生效的曲线编号：应为 31
su -c "grep -o '<lux_table_mode>[0-9]*' /my_product/vendor/etc/display_brightness_config_P_3.xml"

# 实时亮度（0–4674 档位 / 0–4094 背光）
su -c "settings get system screen_brightness"
su -c "cat /sys/class/backlight/panel0-backlight/brightness"
```

**效果要在强光下才看得出来**：室内看不出差别，建议在户外阳光下对比自动亮度的亮度上限。

## 已知情况

- 本模块**不包含**"直写驱动节点强制开启 HBM（阳光屏）"的做法：实测这样做会让手动亮度条失效（需要锁屏再解锁才能恢复），因此弃用
- 本机 ColorOS 未启用框架侧 HBM 触发链路，因此**阳光屏（HBM）仍由系统自身决定**；本模块保证的是自动亮度能顶到滑条满值
- 强光下满亮度使用会带来正常的发热与耗电上升
